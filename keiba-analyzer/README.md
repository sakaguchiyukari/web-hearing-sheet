# Turf Lens（競馬データ分析・予想ツール）

過去のレース結果CSVを読み込み、傾向分析・予想・バックテスト（精度検証）を行う静的Webツールです。
サーバー不要。データはブラウザ内だけで処理されます。

## 使い方

1. `index.html` をブラウザで開く（ローカルサーバー推奨：`python3 -m http.server` など）
2. ページが同梱の公開データ `data/races.csv`（出典情報は `data/meta.json`）を自動で読み込む
   - 同梱データが無い場合は「自分のCSVや架空データを使う」から手動で読み込む（Excel保存なら Shift_JIS）
3. 「02 傾向を分析する」で人気・枠・騎手・調教師・距離・馬場ごとの勝率／複勝率／単勝回収率を確認
4. 「03 出走表から予想する」で出走表を貼り付け → 推定勝率と期待値（推定勝率×単勝オッズ）を表示
5. 「04 精度検証」で、古い80%で学習・新しい20%で答え合わせした結果を確認し、重みを調整

動作確認用に「デモ用の架空データで試す」ボタンがあります。**実在のレース結果ではありません。**

## CSV仕様（1行＝1頭の出走結果）

| 区分 | 列名 |
| --- | --- |
| 必須 | 日付, 競馬場, 距離, 馬名, 着順 |
| 必須（いずれか） | レースID / レース番号 / レース名（レース番号推奨） |
| 推奨 | 芝ダ, 馬場, 枠番, 馬番, 騎手, 調教師, 人気, 単勝オッズ |

- 雛形：`data/template-results.csv`
- 着順が数字でない行（取消・除外・中止など）は集計から除外
- 単勝オッズが無い場合、回収率と期待値は計算されません

## 予想ロジック

1. 人気・騎手・調教師・馬の通算成績・同条件（芝ダ×距離帯）の成績・同コースの枠順ごとに勝率を集計
2. 出走数が少ない値は全体勝率に寄せる（ベイズ縮小、事前サンプル数20）
3. 全体勝率との比の対数を重み付きで合計し、レース内で合計100%になるよう正規化

重みの初期値は仮の値です。必ずバックテストで確認・調整してください。

## 限界（必ず読んでください）

- JRAの単勝払戻率は80%。何も考えずに買えば長期的に約20%減るのが基準です
- 過去に回収率100%超の条件でも、偶然の可能性があります（特に出走数が少ない区分）
- バックテストは確定オッズを使用しており、購入時点のオッズとは異なります
- 調教・血統・展開・馬体重・クラス・斤量などは未考慮です
- 「データ内の最新レースを入れる」で予想したレースは学習データに含まれるため、実力以上に当たって見えます

## データの入手先

- JRA-VAN（JRA公式のデータ提供サービス・有料）：対応ソフトでCSV出力が可能
- JRA公式サイトのレース結果（閲覧用）
- 第三者サイトからの自動取得は、各サイトの利用規約を必ず確認してください
